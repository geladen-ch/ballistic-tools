Eine clientseitige Suite für die äußere Ballistik von Handfeuerwaffen. Alles läuft in Ihrem Browser — es verlassen keine Daten das Gerät. Sie funktioniert nach dem Laden offline und lässt sich auf Desktop und Mobilgerät als App installieren.

App öffnen →

Werkzeuge

Flugbahn

Geschosse fliegen nicht geradeaus. Hier erfahren Sie genau, wie weit daneben — Fall, Windabtrieb, Geschwindigkeit, Flugzeit, auf jede Distanz.

Trefferwahrscheinlichkeit

Trefferwahrscheinlichkeit gegen ein Ziel, unter Berücksichtigung von Wind, Distanzschätzung und Streuungsunsicherheit.

Schießen

Ausgereifter, windschnittiger Ballistikrechner für den Schießstand. Keine unnötigen Informationen.

BC-Werkzeuge

BC anhand bekannter Daten berechnen, zwischen verschiedenen Modellen umrechnen usw.

Cd-Mach-Kurve

Die eigene Widerstandskurve eines Geschosses aus einer Geschwindigkeitstabelle erstellen.

Gewehr-Präzisionsrechner

Gewehrpräzision anhand von Bildern von Zielscheiben mit Treffern messen.

Datenschutz

Wir erfassen keinerlei Daten. Es wird nie etwas an den Server übertragen.
