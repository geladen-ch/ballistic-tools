Набор клиентских инструментов для внешней баллистики стрелкового оружия. Всё выполняется в вашем браузере — данные не покидают устройство. После загрузки работает офлайн и устанавливается как приложение на компьютер и телефон.

Инструменты

Траектория

Пуля никогда не летит по прямой. Вот насколько именно — падение, снос, скорость, время полёта, на любой дистанции.

Вероятность попадания

Вероятность попадания в цель с учётом ветра, ошибки определения дистанции и разброса.

Стрельба

Отточенный баллистический калькулятор для рубежа. Никакой лишней информации.

Инструменты БК

Вычисление БК по известным данным, преобразование между разными моделями и т. д.

Кривая Cd–Mach

Построение собственной кривой сопротивления пули по таблице скоростей.

Целкометр

Измерение кучности винтовки по изображениям мишеней с попаданиями.

Конфиденциальность

Мы не собираем никаких данных. Ничто никогда не передаётся на сервер.
